Anoop Ambrose — Cybersecurity Portfolio
Responsive single-page portfolio focused on SOC operations, SIEM monitoring, incident investigation, penetration testing and vulnerability assessment.
Files
`index.html` — page structure and content
`style.css` — responsive dark theme with red/blue identity and motion styles
`script.js` — accessible mobile navigation, scroll progress, active section state and reveal animations
`assets/` — retain your existing image and other assets
Install
Replace the existing `index.html`, `style.css` and `script.js` with the files in this package. Do not delete the `assets` folder or other existing files.
The hero image expects `assets/web-profile.png`. If that file does not exist in your repository, change the image path in `index.html` to the correct existing profile image path.
Preview
Open `index.html` in a browser, or run `python -m http.server 8000` and visit `http://localhost:8000`.
Publish
Upload/commit the three updated files to `red-blue-single-page-redesign`. Review the GitHub Pages preview before merging that branch into `main`.
